# IT Help Desk Ticket Management System

A Python-based IT support ticket management application that uses SQLite to create, manage, and track technical support requests.

## Project Overview

This project simulates a basic IT help desk environment where support technicians manage employee technical issues, prioritize requests, and track ticket resolution.

## Features

- Create new IT support tickets
- Automatically generate unique ticket IDs
- Assign Low, Medium, or High priority
- View all submitted support tickets
- Update ticket status from Open to Resolved
- Store ticket records using SQLite
- Preserve ticket information between sessions
- Handle invalid menu selections and ticket IDs

## Technologies Used

- Python 3
- SQLite3
- Windows PowerShell
- GitHub

## How to Run

1. Install Python 3.
2. Download `helpdesk.py`.
3. Open PowerShell in the project folder.
4. Run `py helpdesk.py`.
5. Use the menu to create, view, and resolve tickets.
